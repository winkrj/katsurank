# 카츠랭 (katsurank) — 프로젝트 인덱스

> **이 문서가 단일 진실의 출처(SSOT)입니다.** 다른 대화창에서 시작할 때 이 파일을 먼저 읽고 시작하세요.

- **버전**: v0.2
- **갱신일**: 2026-06-04

## 한 줄 요약

서울의 돈까스집을 두고, 사용자가 평생 단 한 표를 던지는 1인 1표 랭킹 사이트.

## 컨셉 핵심

- **표 = 누군가의 1순위라는 진심.** 별점 100개보다 무거움.
- **1인 1표, 표 이동 가능.** 더 맛있는 곳 발견하면 표를 옮길 수 있음.
- **서울 단일 랭킹.** 랭킹은 서울 전체 단 하나뿐이고, **서울 1위**가 왕좌. 지도는 후보를 탐색·핀으로 보는 용도.

```
카츠랭 프로젝트 개발 담당을 맡아줘. 첨부한 02, 03, 05 문서가 기준이야.
코드 작성, 디버깅, 기술 결정 위주로 도와줘. 기획·디자인 결정은

```

```

```

```
기능 우선순위·범위 결정 위주로 도와줘. 1인 개발 + 한 달 일정인 거
항상 염두에 두고 "안 만드는 결정"을 적극적으로 제안해줘.
```

## 운영 규칙

1. **결정이 바뀌면 무조건 문서 업데이트하고 버전 올린다.**
   - 예: 디자인 결정 변경 → `04_brand_design_guide`를 v0.2로 갱신, 변경 이력 기록.
   - 마스터 창에서 *"이거 변경됐어, 문서 업데이트해줘"* 요청 가능.
2. **각 창은 자기 영역만 책임진다.** 다른 영역 결정은 SSOT(이 문서들)를 따른다.
3. **막히면 마스터 창으로.** 30분 막혔으면 가져온다.
4. **문서가 진리, 머릿속이 진리가 아니다.** 헷갈리면 문서부터 확인.
