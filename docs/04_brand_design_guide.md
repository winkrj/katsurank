## 2. 톤 & 매너

- **"돈카츠에 진심"이지만 거슬리지 않게.** 콘텐츠(가게·랭킹)가 주인공, 디자인은 보조.
- **일본 장인 모티프**를 절제해서 사용. 한자 사용은 최소화 (랭킹 숫자에는 한자 X, 명조체 아라비아 숫자만).
- **빨간색은 진짜 정점에만.** 1위, 메인 CTA, 로고 점에만. 그 외는 사용 금지.
- **여백을 두려워하지 않는다.** 빽빽함은 장인 컨셉과 충돌.

## 3. 로고

### 메인 로고 (워드마크형)

- 한글 명조체로 "카츠랭"
- 끝에 도장 빨간 점 하나
- 점은 1픽(one pick)의 시각화

### 사용 규칙

- **헤더·푸터·명함**: 메인 로고 그대로
- **파비콘**: 빨간 점만 사용 (단순 식별)
- **앱 아이콘 (V2)**: 빨간 점 + 베이지 배경

### 보조 요소 — 도장 모티프

- 1위 가게 옆 배지: 빨간 사각형에 명조체 "1"
- 2~3위: 짙은 회갈색 사각형에 명조체 "2", "3"
- 4위 이하: 베이지 배경 + 회색 테두리에 명조체 숫자

## 6. 컴포넌트 가이드

### 랭킹 배지

- **사각형 형태** (도장 컨셉, 둥근 모서리 4px 정도)
- **1위**: 빨강 배경, 베이지 명조체 숫자, 크기 32px
- **2위**: 짙은 회갈색 배경, 베이지 명조체 숫자, 크기 28px
- **3위**: 중간 회갈색 배경, 베이지 명조체 숫자, 크기 28px
- **4~10위**: 베이지 배경 + 회색 보더, 회갈색 명조체 숫자, 크기 28px

### 지도 마커

- **1위**: 원형 30px, 빨강 배경, 베이지 명조체 "1", 호버 시 가게명 툴팁
- **2~3위**: 원형 26px, 짙은/중간 회갈색
- **4~10위**: 원형 14px, 옅은 회갈색 + 흰 보더 (숫자 없음)
- **그 외**: 원형 10px, 더 옅은 색

### 카드

- 흰 배경
- 0.5px 옅은 회베이지 보더
- border-radius: 8px (둥근 모서리 최소)
- 그림자 없음 (장인 컨셉)

### 버튼

- **Primary (투표)**: 빨강 배경, 베이지 텍스트
- **Secondary**: 베이지 배경 + 짙은 회갈색 보더, 먹색 텍스트
- 그라데이션 없음, 그림자 없음

## 7. 아이콘
