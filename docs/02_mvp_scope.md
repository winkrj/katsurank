# MVP 범위 정의 — 버전별

- **버전**: v0.1
- **작성일**: 2026-05-11

이 문서는 **각 버전에 무엇이 들어가고 무엇이 빠지는지** 명확히 못 박아두기 위한 문서입니다. 1인 개발에서 가장 큰 적은 *"이거 하나만 더 넣자"* 입니다.

## V1 (MVP) — 출시 목표 1개월

### 들어가는 것 (Must Have)

#### 인증
- [ ] 카카오 OAuth 로그인 / 로그아웃
- [ ] 카카오에서 받는 정보: 카카오 고유 ID, 닉네임, 프로필 이미지만

#### 메인 화면
- [ ] 카카오맵 JS SDK 기반 지도
- [ ] 지도 위 마커 표시 (1위 강조 / 2~10위 강조 / 나머지 일반)
- [ ] 지도 줌·이동에 따라 사이드/하단 랭킹 동적 갱신
- [ ] 데스크탑: 우측 사이드바에 랭킹 TOP N
- [ ] 모바일: 하단 시트(bottom sheet)에 랭킹
- [ ] 30초마다 자동 폴링으로 랭킹 갱신

#### 가게 상세
- [ ] 가게 이름, 주소, 카카오맵 카테고리
- [ ] 현재 표 수, 현재 순위
- [ ] 영업시간·전화 (카카오맵 API에서 제공되는 경우)
- [ ] 카카오맵 외부 링크 (길찾기는 카카오맵으로 위임)
- [ ] 투표 / 투표 변경 버튼

#### 투표
- [ ] 1인 1표
- [ ] 표 이동 가능 (이전 가게 -1, 새 가게 +1)
- [ ] 동시성 처리 (낙관적 락 `@Version` 또는 비관적 락)

#### 가게 추가
- [ ] 카카오맵 로컬 API로 검색
- [ ] 검색 결과에서 선택해서 등록
- [ ] `kakao_place_id`로 중복 차단
- [ ] 카테고리 검증 (돈까스/돈가스/경양식)

#### 검색
- [ ] 가게 이름 검색 (자체 DB)

#### 마이페이지
- [ ] 현재 내 1순위 가게 표시
- [ ] 표 이동 히스토리 (시간순)
- [ ] 로그아웃

#### 기타
- [ ] 개인정보처리방침 페이지
- [ ] 이용약관 페이지 (간단한 템플릿)
- [ ] 초기 가게 20곳 수동 등록

### 안 들어가는 것 (V1.1+로 미룸)

- ❌ OG 이미지 자동 생성
- ❌ 지역(구 단위) 필터
- ❌ 어뷰징 모니터링 대시보드
- ❌ 메뉴·가격 정보
- ❌ 사진 업로드
- ❌ 푸시 알림
- ❌ 진짜 실시간 (WebSocket)
- ❌ 가입일 검증·표 이동 쿨타임 (검토 후 결정)

### 검토 중

- [ ] 푸시 알림 (표 변동·랭킹 변동)

- [ ] 사진 업로드 (저작권·관리 문제 해결 후)
- [ ] **카테고리 확장**: "인생 라멘", "인생 김밥" 등
  - V1에서 `Restaurant.category` 필드 미리 준비
- [ ] 친구 기능 (선택)
- [ ] 추천 시스템 ("이 집을 1순위로 꼽은 사람들의 다른 후보")

## 의사결정 원칙

기능 추가/변경 요청이 올 때마다 이 질문을 한다:

1. **이게 없으면 출시 못 하나?** (No → V1.1+로 보냄)
2. **1인 개발자가 한 달 안에 만들 수 있나?** (No → V1.1+)
3. **이게 컨셉(1인 1표·표 이동·신뢰)을 강화하나?** (No → 폐기 검토)
