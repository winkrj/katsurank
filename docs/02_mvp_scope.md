# MVP 범위 정의 — 버전별

- **버전**: v0.4
- **작성일**: 2026-09-01

이 문서는 **각 버전에 무엇이 들어가고 무엇이 빠지는지** 명확히 못 박아두기 위한 문서입니다. 1인 개발에서 가장 큰 적은 *"이거 하나만 더 넣자"* 입니다.

> 아래 체크박스는 출시 범위 정의를 보존한 것이며 현재 구현 완료표가 아니다. 실제 코드·브랜치·검증
> 상태는 `09_current_status.md`를 기준으로 판단한다.

---

## V1 (MVP) — 출시 목표 1개월

### 들어가는 것 (Must Have)

#### 인증
- [ ] 카카오 OAuth 로그인 / 로그아웃 (REST API + 외부저장소 세션 방식)
- [ ] 카카오에서 받는 정보: 카카오 고유 ID, 닉네임, 프로필 이미지만

#### 메인 화면 (= 유일한 화면)
- [ ] 화면은 지도 하나뿐. 별도의 홈/랭킹/지도/검색/마이페이지 라우트를 두지 않는다.
- [ ] 카카오맵 JS SDK 기반 지도 (후보 가게 핀 표시, 탐색용)
- [ ] 지도 위 마커는 순위 구간별로 계층을 둔다: **1위**(왕관·최상위 강조) / **2~3위**(진한 골드) / **4~10위**(옅은 골드 아웃라인) / **11위 이하**(무채색 아웃라인)
- [ ] **서울 단일 랭킹 패널** (1위=왕좌 강조) — 데스크탑: 좌측 사이드바 TOP N / 모바일: 하단 시트로 열고 닫기
- [ ] **실시간 갱신**: 누군가 투표하면 화면을 보고 있는 모든 사용자에게 반영된다. SSE(Server-Sent Events)는 signal-only가 아니라 version과 변경·생성 시각, TOP 20 전체를 담은 스냅샷을 보낸다. 기존 REST 랭킹 API는 유지하며 프론트 Query cache를 스냅샷으로 직접 갱신한다. 최신 프론트와 백엔드의 이벤트 이름 정렬·통합 검증은 `09_current_status.md`에서 추적한다.

> ⚠️ v0.1의 "지도 줌·이동에 따라 사이드/하단 랭킹 동적 갱신"(뷰포트 랭킹)은 **폐기됨.** 랭킹은 서울 전체 단 하나이며 지도 영역과 무관. 지도는 핀·탐색 용도.

#### 가게 상세
- [ ] 별도 페이지가 아니라, 지도 화면 위에 뜨는 **패널(데스크탑: 좌측 사이드바가 상세로 전환) / 모달(모바일: 화면 위로 올라옴)** 로 처리
- [ ] 가게 이름, 주소, 카카오맵 카테고리
- [ ] 현재 표 수, 현재 서울 순위
- [ ] 영업시간·전화 (카카오맵 API에서 제공되는 경우)
- [ ] 카카오맵 외부 링크 (길찾기는 카카오맵으로 위임)
- [ ] 투표 / 투표 변경 버튼
- [ ] **공유하기**: 이 가게로 바로 연결되는 링크(`?restaurant=가게ID`) 생성. 네이티브 공유 시트 지원 기기는 그걸로, 아니면 링크 복사로 대체. 그 링크로 들어오면 지도가 해당 가게로 자동 포커싱되고 상세도 자동으로 열림

#### 투표
- [ ] 1인 1표
- [ ] 표 이동 가능 (이전 가게 -1, 새 가게 +1)
- [ ] 동시성 처리 (낙관적 락 `@Version` 또는 비관적 락)

#### 가게 추가
- [ ] 별도 페이지가 아니라 지도 화면 위에 뜨는 모달로 처리 (검색 → 위치 확인 → 최종 확인 3단계 유지)
- [ ] 카카오맵 로컬 API로 검색
- [ ] 검색 결과에서 선택해서 등록
- [ ] `kakao_place_id`로 중복 차단
- [ ] 카테고리 검증 (돈까스/돈가스/경양식)

#### 검색
- [ ] 가게 이름 검색. 지도 화면에 늘 떠 있는 검색창 하나로 처리 (별도 검색 페이지 없음)

#### 내 표 확인
- [ ] 별도 마이페이지 없이, 랭킹 패널 안에 "내 한 표" 카드로 상시 노출
- [ ] 현재 내 1순위 가게 표시, 클릭 시 그 가게 상세로 이동
- [ ] 표 이동 히스토리 (시간순)
- [ ] 로그아웃 (헤더)

#### 기타
- [ ] 개인정보처리방침 페이지
- [ ] 이용약관 페이지 (간단한 템플릿)
- [ ] 초기 가게 20곳 수동 등록

### 안 들어가는 것 (V1.1+로 미룸)

- ❌ OG 이미지 자동 생성
- ❌ 지역(구 단위) 필터
- ❌ 어뷰징 모니터링 대시보드
- ❌ 메뉴·가격 정보
- ❌ 사진 업로드
- ❌ 푸시 알림
- ❌ 웹소켓 (양방향 통신 불필요 — 실시간 갱신은 SSE로 충분)
- ❌ 가입일 검증·표 이동 쿨타임 (검토 후 결정)

## 의사결정 원칙

기능 추가/변경 요청이 올 때마다 이 질문을 한다:

1. **이게 없으면 출시 못 하나?** (No → V1.1+로 보냄)
2. **1인 개발자가 한 달 안에 만들 수 있나?** (No → V1.1+)
3. **이게 컨셉(1인 1표·표 이동·신뢰)을 강화하나?** (No → 폐기 검토)

## 변경 이력

- **v0.1 (2026-05-11)**: 초안. V1·V1.1·V2 구분 확정.
- **v0.2 (2026-06-04)**: 메인 화면 랭킹을 **서울 단일 랭킹**으로 재정의(뷰포트 동적 랭킹 폐기, 지도는 핀·탐색 용도). 인증을 REST API + 외부저장소 세션 방식으로 명시. V1.1 지역 필터를 "탐색 보조"로 한정(구별 별도 랭킹 없음). 가게 상세의 순위를 "서울 순위"로 명확화.
- **v0.3 (2026-08-01)**: **화면 구조를 지도 원페이지로 전환** — 홈/랭킹/지도/검색/마이페이지 라우트를 폐기하고 지도 화면 하나로 통합. 가게 상세·가게 등록은 지도 위 패널/모달로 처리. 지도 마커를 순위 구간별 4단계 색상 계층으로 구체화(1위/2~3위/4~10위/11위 이하). **랭킹 갱신 방식을 30초 폴링 → SSE 이벤트 기반 실시간 갱신으로 변경**("안 들어가는 것"의 웹소켓 항목은 유지 — SSE는 단방향이라 웹소켓과 별개). 가게 상세에 공유하기(딥링크 `?restaurant=`) 기능 추가.
- **v0.4 (2026-09-01)**: SSE 계약을 실제 구현에 맞춰 signal-only 설명에서 versioned TOP 20 스냅샷 전파로 정정. 브랜치 통합 상태는 `09_current_status.md`로 분리.
